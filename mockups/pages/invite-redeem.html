2. A password that's already been breached

That password has shown up in a known data breach elsewhere on the internet, so we won't use it. Choose a different one — it doesn't need to be complicated, just not one that's already out there.

SPEC §4.6.1: passwords are screened against the public corpus of known-breached passwords via a k-anonymity range query — only a hash prefix ever leaves the server, never the password or the user's identity — and a match is "refused with an honest explanation."

3. A display name that isn't allowed

That name isn't allowed on WeeBee. Please choose a different one.

SPEC §4.5: every name, at signup and at every later change, is checked against operator-curated NAME_BLOCKLIST and "rejected at save time with an honest message." The message above is deliberately generic rather than quoting the list back, since the list itself is never shown to users; SPEC gives no verbatim wording for this message — see mockups/NOTES.md.
