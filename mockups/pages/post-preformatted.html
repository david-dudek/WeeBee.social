Single-post view of a preformatted post (SPEC §7.2.1) — the platform's one documented exception to the reflow requirement, permitted under WCAG 1.4.10's two-dimensional-layout exemption. Monospace here is structural, not theming (SPEC §9.1.1): it survives every theme, including the viewer override. Only the monospace-ness is exempt from reflow — nothing else on this page is.

Runs of spaces are preserved exactly — the columns above line up because nothing collapsed them. Long lines never soft-wrap; on a screen narrower than the content, the box above scrolls sideways instead of the text reflowing.

The obligations that come with this reflow exemption (ARCHITECTURE §3.8):

  • The scrolling region carries tabindex="0", an accessible name ("Preformatted post content, scrolls horizontally"), and a visible focus ring on keyboard focus — a horizontally scrollable region that only a mouse can pan fails WCAG 2.1.1.
  • The horizontal scroll is confined to the post's own container. Resize this page to 320 px: the page itself never scrolls sideways, only the box above does.
