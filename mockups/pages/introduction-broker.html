Introduce two friends

SPEC §5.5(a): David selects two of his own friends who aren't friends with each other, and each receives an auto-generated introduction to the other — "both free-text-free, both requiring consent, both silent on decline." Nowhere in this flow does David write anything to either of them.

Both pickers list the same alphabetical friend list as the friends page and the preview-as picker — in the real product each list would exclude anyone already friends with the other choice, which this mockup's cast carries no data to compute, so Ben and Grace are simply pre-picked as this worked example's pair, per §5.5(a)'s own requirement that neither is already friends with the other.

2. What Ben receives

Per §5.5(a)'s own wording: "M wants to introduce you to [other party]" plus the other's basic-tier profile and auto-generated context (shared hashtags, mutual friends). Grace's side of the same card is not rebuilt separately here — it is the identical component, fed from Ben's data instead.

Grace and Ben are two of the five names CRIB.md §3 adds "purely to give friends.html's alphabetical list something real to sort" — with "no further backstory." Inventing a bio or hashtags for either here would contradict that. The photo, short bio and hashtags fields are therefore shown as placeholders rather than invented content; only "knows David," which is simply true — both are David's own friends — renders as real text. Compare Priya's request card, where a short bio was invented because Priya's own established facts (a hiking hashtag match, one mutual friend) called for one.

3. If it doesn't complete

If either Ben or Grace declines, the introduction does not complete. Per §5.5(a): "the other candidate is never told an introduction was attempted or declined" — if Ben declines, Grace is never told anything happened at all, not even that someone declined. David sees only this:

Your introduction of Ben and Grace didn't complete.

Which one declined is never shown, here or anywhere — rendering it more specifically than this would name a private decision Ben or Grace made. If both had accepted instead, the introduction would simply complete: Ben and Grace become friends, with no confirmation beyond each now finding the other in their own friends list.
