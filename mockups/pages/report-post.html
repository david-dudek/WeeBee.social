Report a post or comment

If something you can see on WeeBee crosses a line, you can report it to the person who runs the platform. Reporting doesn't take anything down by itself — it puts a copy in front of them so they can look and decide what to do. Whatever you reported stays visible while they're looking at it.

SPEC §13.2, §13.3: the report button is a real, visibly labelled <button>, never an unlabelled icon, and it is available to anyone who can see the target — never to the post's or comment's own author. §13.3: reported content stays live while a report is open, which is why nothing on this page should read as though anything has already been removed.

Reporting a post

Priya can report this post; David, its author, could not — the button would not appear on his own view of it at all.

David Several days ago

Back from three days on the Cornwall coast path — legs are done, but I'd do the whole thing again tomorrow. Already thinking about where next.

Visible to: all of David's friends, and friends-of-friends with any of #hiking, #jazz.

What's wrong with this post?

Reason

Reasons are verbatim from SPEC §13.2: harassment or abuse · unwanted or commercial content · someone else's private information · the tags don't match this post (profile posts only) · something else. "The tags don't match this post" only ever applies to a profile post like this one — see the comment report below, where it's absent. §13.2, v1.21: tag-mismatch reports exist because tagging is an audience control (§7.9), and this is the one report reason the affected friend-of-friend — the person the mismatch actually reached — is best placed to raise.

Reporting a comment

Back to David's own point of view for this one — the same dinner post and comment already shown on post-feed.html. David didn't write Alice's comment, so he can report it even though he's the post's author; he could not report his own comment the same way.

David A few days ago

Small dinner this Friday if anyone's free — nothing fancy, just good company and too much pasta. Let me know and I'll set a place for you.

Visible to: the friends David sent this to.

  1. Alice A couple of days ago

    I'm in! Should have known you'd pick the one week I'm swamped at work, but I'm not missing this — I'll rearrange whatever I have to.

What's wrong with this comment?

Reason

Same reason list as the post above, minus "the tags don't match this post" — a comment carries no hashtags of its own, so that reason has nothing to attach to here. The frozen copy this report captures is what lets the operator judge it even after the comment is later edited or deleted (§13.2, §13.3).

A note on an ambiguity in SPEC §13.2, flagged rather than resolved here: its own sentence — "there is one report form, and it always carries a reason category, plus the optional short note to the operator this section already gives profile reports" — reads most plainly as extending the free-text note above to post and comment reports too, which is what both forms on this page render. But the sentence is not fully explicit that the note belongs on every report type rather than profile reports alone, and this session renders the plainest reading without resolving that ambiguity.
