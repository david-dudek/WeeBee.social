Gallery image overlay, open

The click-to-expand overlay of §7.2.2, reached here from the second thumbnail on David's Photos tab. It is a proper modal dialog per §16.3: keyboard-openable, focus-trapped, Escape-dismissable, focus restored on close — and an in-app view, never a raw file URL. Because these are static pages with no scripts, this page shows the resulting state already open rather than the click itself; the two sections below stand for the two layers a real click would produce.

The page behind the dialog

Dimmed and inert while the dialog is open — a real focus trap keeps keyboard focus from reaching it at all, not merely a visual fade.

The dialog, open

What a real click would do, that a static page cannot: move focus onto this dialog when it opens; trap focus inside it while open, so Tab cycles among Previous, Next, Close and the image without ever reaching the dimmed page behind; close on Escape; and return focus to the second gallery thumbnail afterward. Previous and Next are real buttons, so a keyboard user can step through all 8 images without closing and reopening the dialog each time (§16.3). The image's alternative text is shown as a visible caption in a <figure>/<figcaption>, with the image's own alt left empty so nothing is announced twice (§9.4). Zoom and pan, where the image is larger than the screen, are operable by keyboard as well as by pointer.
