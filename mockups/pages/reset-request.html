Reset your password

Enter the email address for your WeeBee account and we'll send a 6-digit code you can use to set a new password.

SPEC §4.6.1: password reset is completed with a short, single-use, time-limited numeric code, entered on a page reached "by navigating to the site themselves" — never by clicking a link in an email. This page is that starting point; login.html links here, rather than any email doing so.

If you've been locked out of logging in

You've made too many attempts to log in, so login is temporarily locked for a little while. You can wait about 15 minutes and try again, or reset your password right now using the form above.

SPEC §4.6.1, §13.6: login attempts are rate-limited per account and per source address, with exponential backoff and temporary lockout (LOGIN_ATTEMPT_LIMIT ≈ 5, LOGIN_LOCKOUT_MINUTES ≈ 15). §16.3 requires a message like this to use a polite live region and to be honest about the fix, not just refuse silently. It's rendered here, on the reset page, rather than on login.html itself — see mockups/NOTES.md for why this session split this page pair's two required states the way it did.
