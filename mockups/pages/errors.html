Errors and empty states

One page collecting the error and empty states SPEC §16.1 puts in scope, rather than one file per case. Each numbered section below is its own state, shown at once rather than live.

1. When you can't see something

This page isn't here, or you don't have permission to see it.

SPEC gives no verbatim wording for this message; the sentence above is this session's own honest phrasing, deliberately identical regardless of cause — see mockups/NOTES.md. SPEC §9.3: "a viewer who may not see a profile gets one response," identical across all five cases below, and any difference between them "is an oracle." Listed here for the founder's benefit, not shown to a real visitor, who only ever sees the one sentence above:

  • a block (§5.4)
  • no mutual friend
  • a deactivated account (§4.7)
  • a banned account (§13.2.1)
  • a profile that never existed

2. A rate limit — the general case

You've reacted to quite a few things in a short time. You can react again in 2 minutes.

SPEC §13.6: "all social actions are rate-limited per account per day... hitting one produces an honest 'slow down' message." Reactions are used here as one worked example among the several kinds of action this limit covers.

3. The feed-post spacing message

Slow down — you can post again in 8 minutes.

SPEC §13.6, verbatim pattern: "slow down, you can post again in N minutes." POST_MIN_INTERVAL_MINUTES ≈ 10; profile (blog) posts are exempt from this particular limit.

4. An empty feed

Nothing here yet. When a friend posts something meant for you, or posts to their own blog, it'll show up here.

A genuine empty state — the platform is allowed to say plainly that a feed has nothing in it. This is a different rule from §8.2.2's reaction-line requirement, which forbids exactly this kind of message for reactions specifically: "no empty state, no 'no reactions yet', which is a count of zero written out in words." The feed above is allowed to say "nothing here yet" because it isn't counting anything; a reaction line naming zero reactions would be.
